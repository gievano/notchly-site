# notchly-site

The landing page for [notchly](https://github.com/gievano/notchly), a small mac-style overlay for Windows.

## Preview

The page includes a CSS-built desktop/product mockup with interactive Music, Focus, Shelf, and Todo views. The site is plain HTML, CSS, and JavaScript with no build step or runtime dependencies.

## Develop locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server.

## Deploy

GitHub Pages deploys the site from `main`. Changes merged to `main` become the published site after the Pages deployment finishes.

Live site: https://gievano.github.io/notchly-site/
